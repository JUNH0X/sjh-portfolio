SJH Portfolio — 사진 첨부 업데이트

변경 사항
- 포트폴리오 올리기 / 연구 기록 쓰기: 사진 첨부 및 즉시 미리보기
- 사진 형식: PNG, JPG, WebP, GIF / 최대 5MB
- 링크와 사진은 모두 선택사항
- 저장된 링크는 클릭형 미리보기 카드로 표시하며, YouTube/Vimeo/CodePen/Figma는 지원되는 URL에 한해 실제 임베드를 표시
- 기록 카드와 홈 미리보기에 첨부 사진 표시
- 기존 기록 수정 폼에서도 사진 미리보기와 새 사진 교체 지원
- 이미지는 서버 함수에서 Supabase Storage로 업로드하며, service_role 키는 서버 환경변수에만 둡니다.

기존 Supabase 프로젝트를 사용 중이라면 먼저 다음 파일을 실행하세요.
  supabase/photo-attachments-migration.sql

실행 방법
1. Supabase Dashboard → SQL Editor에서 위 SQL 파일을 열고 전체 내용을 실행합니다.
2. ZIP 안의 프로젝트 파일을 기존 저장소 파일에 덮어씁니다. 특히 app.js, styles.css, functions/api/admin.js, supabase/schema.sql을 포함해야 합니다.
3. Cloudflare Pages가 새 커밋을 배포하도록 프로젝트 파일을 GitHub에 업로드합니다.
4. 배포 후 관리자 도구에서 포트폴리오/연구 기록 등록을 테스트합니다.

주의
- record-images 버킷은 공개 버킷입니다. 사진 URL을 아는 사람은 이미지를 볼 수 있으므로 개인정보나 비공개 사진은 첨부하지 마세요.
- 사진 업로드는 Cloudflare Pages 환경변수 SUPABASE_URL 및 SUPABASE_SERVICE_ROLE_KEY가 올바르게 설정되어 있어야 합니다.


링크 임베드 참고
- YouTube/Vimeo/CodePen/Figma: 실제 임베드(iframe) + 원본 링크
- GitHub/Hugging Face/일반 웹사이트: 미리보기 카드(도메인, 경로, 제목, 원본 링크)
- 외부 서비스에서 임베드를 차단하거나 링크 형식이 다르면 미리보기 카드가 표시됩니다.
